1. Landing Page & Ad System

Hero & Search

  • Prominent job search bar (keyword + location)
  • Country & category quick filters (GCC, admin can add countries)
  • Featured job slots (sponsored, paid placement)
  • Latest jobs grid with timestamp
  • Walk-in interview section
  • Salary guide links per country
  • WhatsApp group/channel join button

Landing Page Ad Type — Admin Configurable

  • Admin sets landing page ad type from 3 options: Google AdSense Product Banner WhatsApp Channel Link
  • Can switch ad type anytime from admin panel
  • Can enable/disable each type independently

Rewarded Ad to Unlock More Jobs

  • Guest users see limited job preview (e.g. 5 jobs)
  • "Watch Ad to unlock more" prompt appears
  • Google Rewarded Ad plays → user can skip after 5s → more jobs unlock
  • Admin can enable/disable this feature globally Toggle
  • Admin sets how many free jobs show before ad gate
  • Logged-in users bypass ad gate

Category-wise Ad Control

  • Admin can enable/disable ads per category Category-wise
  • If ads disabled for a category, UI auto-adjusts layout to fill space
👤

2. Job Seeker Features

Registration & Login

  • Email + Password registration
  • Google OAuth login
  • LinkedIn OAuth login
  • Mobile phone OTP login (SMS verification) New
  • User approval flow — Admin can set: Auto-approve / Manual approval / Rejection New

Profile & CV

  • Profile builder (photo, name, nationality, location, skills, languages)
  • Work experience & education sections
  • CV upload (can be globally disabled by admin to save storage) Toggle
  • In-platform CV builder (can be enabled/disabled) Toggle
  • Profile completion percentage indicator

Job Search & Discovery

  • Search by keyword, country, city, category, industry
  • Filter by experience level, job type, salary range
  • Save/bookmark jobs
  • Recommended jobs based on profile
  • Job alerts via email + push notifications

Applications

  • Apply based on employer/admin setting (email, URL, in-app, WhatsApp)
  • Track applications: Applied → Viewed → Shortlisted
  • Application history dashboard

Premium Candidate Disabled at Launch

  • Free users: limited to 5 job views (configurable by admin)
  • Premium users: unlimited job views + priority profile visibility
  • Admin can enable/disable premium gate anytime Toggle
  • Payment via Stripe or PayPal
🏢

3. Employer / Recruiter Features

Registration & Login

  • Company registration with profile (logo, description, industry, size, location)
  • Email / Google / LinkedIn login
  • Mobile OTP login option
  • Admin approval: Auto / Manual / Reject New
  • Banner ads shown on employer login/dashboard page (admin configurable) New

Job Posting

  • Post jobs with full details (title, description, requirements, salary, location, category)
  • Set apply method per job: Email / External URL / In-app / WhatsApp/Phone
  • Free job post limit set by admin (e.g. 3 free posts/month) New
  • Additional posts require payment (Stripe / PayPal) New
  • Job post expiry management
  • Boost/sponsor job post for top placement (paid)

Dashboard

  • View applicants per job post
  • Application pipeline (Applied, Viewed, Shortlisted, Rejected)
  • Analytics: job views, clicks, application count
  • Manage active/expired job posts
  • Billing & payment history
⚙️

4. Admin Panel — Full Control

User Management

  • View all job seekers and employers
  • Approval system: Auto-approve / Manual approve / Reject per user type New
  • Suspend, ban, or delete accounts
  • View full candidate profile and application history
  • Export candidate database (CSV/Excel)

Job & Category Management

  • Approve / reject / delete job posts
  • Add, edit, remove job categories
  • Enable/disable any category entirely New
  • Category-wise settings for ads, banners, apply method

Apply Method Settings

  • Set global default apply method (Email / URL / In-app / WhatsApp)
  • Override apply method per category (e.g. Accounting = Email, IT = In-app)
  • Enable/disable each apply method anytime
  • Employer can further set their own apply method (within admin allowed options)

Country & Location Management

  • Add/remove countries (GCC by default)
  • Add/remove cities per country
  • Enable/disable any country from listings

Ad & Banner Management

  • Google AdSense placement control (header, sidebar, between listings)
  • Enable/disable ads globally or per category
  • Rewarded ad toggle (on/off)
  • Set free job preview count before ad gate triggers
  • Landing page ad type selector: Google Ad / Product Banner / WhatsApp Link
  • Employer login page banner management New
  • UI auto-adjusts when banners/ads are disabled

Employer Limits & Billing

  • Set free job post limit per employer (global or per company)
  • Configure pricing for additional posts
  • Configure Stripe and PayPal credentials from admin panel
  • View all transactions and revenue

Premium Candidate Settings Disabled at Launch

  • Enable/disable premium candidate feature
  • Set free job view limit for non-premium users
  • Set premium pricing plans

CV & Media Settings

  • Enable/disable CV upload globally New
  • Enable/disable profile photo upload
  • If CV upload disabled: apply redirects to email automatically
  • Storage usage monitor in admin dashboard

Platform Analytics

  • Total users, jobs, applications, employers
  • Daily/weekly/monthly traffic stats
  • Revenue dashboard (ads + payments)
  • Top performing job categories
  • Most searched keywords
🛍️

5. Product Banner System

  • 2–3 product banner slots on every job detail page
  • Each banner: image + product title + short description + link to product detail page
  • Global banners: show on all job posts regardless of category
  • Category-wise banners: IT jobs → tech product banners, HR jobs → HR software banners, etc.
  • Admin can add, edit, remove products from panel
  • Admin can assign products globally or per specific category
  • Admin can enable/disable banners per category anytime New
  • When banners disabled for a category, UI auto-adjusts (no empty space)
  • Product detail page: full description, price, external purchase link
  • Banner click tracking (impressions + clicks analytics in admin)
💳

6. Payment System

MethodUsed ForStatus
StripeEmployer extra job posts, premium candidates, featured listingsConfigurable from admin panel
PayPalSame as Stripe — alternative optionConfigurable from admin panel
Manual/InvoiceEnterprise employers — offline paymentAdmin can record manually
  • Admin enters Stripe/PayPal API keys directly from admin panel — no code change needed
  • Can enable Stripe only, PayPal only, or both
  • All transactions logged with receipt generation
  • Premium candidate payment gate: disabled at launch, enable anytime

7. CV & Media Management

  • CV upload: globally enabled/disabled from admin panel New
  • Profile photo upload: enabled/disabled separately
  • Company logo upload: enabled/disabled separately
  • When CV upload disabled: "Apply via Email" auto-activates as fallback
  • Email apply redirects candidate to send CV via their email client automatically
  • Storage usage displayed in admin dashboard
  • At launch: CV upload DISABLED, email apply ENABLED Default
  • Can be enabled later when storage budget allows
