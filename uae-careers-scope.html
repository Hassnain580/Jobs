1. Landing Page & Ad System

Hero & Search

  • Prominent job search bar (keyword + location)
  • Country & category quick filters (GCC, admin can add countries)
  • Featured job slots (sponsored, paid placement)
  • Latest jobs grid with timestamp
  • Walk-in interview section
  • Salary guide links per country
  • WhatsApp group/channel join button

Landing Page Ad Type — Admin Configurable

  • Admin sets landing page ad type from 3 options: Google AdSense Product Banner WhatsApp Channel Link
  • Can switch ad type anytime from admin panel
  • Can enable/disable each type independently

Rewarded Ad to Unlock More Jobs

  • Guest users see limited job preview (e.g. 5 jobs)
  • "Watch Ad to unlock more" prompt appears
  • Google Rewarded Ad plays → user can skip after 5s → more jobs unlock
  • Admin can enable/disable this feature globally Toggle
  • Admin sets how many free jobs show before ad gate
  • Logged-in users bypass ad gate

Category-wise Ad Control

  • Admin can enable/disable ads per category Category-wise
  • If ads disabled for a category, UI auto-adjusts layout to fill space

15. SEO Strategy — Built Into the Code

Technical SEO (Next.js Advantages)

  • Server-Side Rendering (SSR) for all job listing pages — Google indexes content instantly
  • Static Generation (SSG) for category, country, and city pages
  • Dynamic sitemap.xml — auto-updates when new jobs are posted
  • robots.txt — properly configured for crawlers
  • Canonical URLs — no duplicate content issues
  • Page speed optimized — Core Web Vitals (LCP, CLS, FID) targets met
  • Mobile-first responsive design (Google mobile-first indexing)
  • Structured Data (JSON-LD) on every job post — enables Google rich results / job cards

On-Page SEO (Per Job Post)

  • Auto-generated SEO title: "Senior Accountant Jobs in Dubai, UAE — UAE Careers"
  • Auto-generated meta description from job description snippet
  • Open Graph tags — rich previews when shared on WhatsApp, LinkedIn, Twitter
  • Twitter Card tags
  • Proper H1 → H2 → H3 heading hierarchy on every page
  • Alt text auto-generated on all images
  • Clean SEO-friendly URL structure: /jobs/senior-accountant-dubai-uae

Auto-Generated Content Pages

URL PatternPurpose
/jobs/dubaiJobs in Dubai — city landing page
/jobs/uae/accountingAccounting jobs in UAE — category + country
/jobs/saudi-arabiaJobs in Saudi Arabia — country page
/salary-guide/uaeUAE Salary Guide 2026 — evergreen content
/companies/[company-name]Indexed company profile pages
/category/[category-name]Category landing pages with keyword-rich content

Local & Regional SEO (GCC Focus)

  • Country + city specific pages for all GCC locations
  • Arabic language support with RTL layout — ranks in Arabic Google searches
  • Hreflang tags (English + Arabic) to target both language audiences
  • Google Business Profile integration guidance for employers

Link Building & Authority

  • Job sharing buttons (WhatsApp, LinkedIn, Twitter) generate natural backlinks
  • Employer company pages indexed as separate SEO entities
  • Sitemap submitted to Google Search Console + Bing Webmaster Tools
  • WhatsApp channel drives repeat traffic and social signals

Performance (Core Ranking Factor)

  • Image lazy loading + WebP format for faster load
  • Font optimization (preload, subset)
  • CSS/JS minification and code splitting
  • CDN via Vercel Edge Network — global fast load from nearest server
  • Target: 90+ Lighthouse Score across all pages

16. Ad Gate — Close Button Timer

  • Admin sets exact number of seconds before "Skip / Close" button appears on rewarded ad
  • Configurable from admin panel — no code change required
  • Separate timer settings for Web (AdSense rewarded) and Mobile (AdMob rewarded)
  • Minimum allowed seconds: 0 (instant close) — Maximum: admin-defined cap (e.g. 30s)
  • Default at launch: 5 seconds
  • Timer countdown shown to user ("Skip in 4… 3… 2… 1…")
  • Admin can enable/disable the countdown display separately
🎯

17. Landing Page — Category-wise Ad Targeting

  • Admin assigns specific ads or landing page variants per job category
  • Example: IT category landing page shows tech product banners; HR category shows HR software banners
  • Each category can have its own: Google AdSense slot / Product banner set / WhatsApp channel link
  • Admin maps: Category → Ad Type → Specific Ad/Banner/Link
  • Unconfigured categories fall back to global landing page ad setting
  • Multiple landing page templates can be created — admin assigns per category
  • Category ad targeting applies to both web and mobile app
  • Enable/disable category-level ad targeting anytime from admin panel

19. Fraud Warning Notice System

Default Notice Text:

⚠️ Notice: uaecareer.ae is not a recruiter. We only share publicly available walk-in opportunities. Never pay anyone for job applications, interviews, tests, or recruitment processes. Genuine walk-ins are always free.

Report fraud to: ask@uaecareer.ae
  • Notice displayed on key pages: Homepage, Job Detail, Job Listings, Search Results, Apply Page, Employer Registration, Job Seeker Registration
  • Mobile app: shown on Job Detail screen, Home screen, Apply screen
  • Admin can edit full notice text from admin panel — no code change required
  • Admin can change fraud report email anytime
  • Admin can enable/disable notice per page individually
  • Notice position configurable: top banner / bottom bar / inline within content
  • Dismissible by user (with cookie memory) or set as permanent by admin
  • Separate notice variants possible per category if needed

22. Image Compression

  • Profile photos auto-compressed on upload (before saving to storage)
  • Target output: under 100KB per profile photo
  • Compression applied on both web (browser-side) and mobile app (device-side) before upload
  • Format converted to WebP automatically (smaller size, same quality)
  • Company logos: compressed to under 150KB
  • Banner images: compressed to under 300KB
  • Admin can set max file size limits per upload type from admin panel
  • Users shown preview of compressed image before confirming upload
  • No third-party paid service needed — compression handled in-app using Sharp (Node.js library, free)

24. AI / LLM Features

Supported LLM Providers (Admin Configures)

  • OpenAI (ChatGPT — GPT-4o, GPT-4)
  • Anthropic (Claude — claude-sonnet-4-6, claude-opus-4-8)
  • Google (Gemini — Gemini 1.5 Pro)
  • DeepSeek (DeepSeek-V3 — cheapest option)
  • Admin enters API key for chosen provider from admin panel — no code change
  • Admin can switch provider anytime

LLM Configuration Modes

ModeWho ConfiguresDetail
Global ModeAdmin onlyOne LLM configured for entire platform. All AI features use company's API account. Employers have no access to LLM settings.
Employer ModeEach EmployerAdmin enables employer-level LLM configuration. Each employer adds their own API key. Can upload a PDF guide/prompt to customize AI behavior for their job posts.
  • Admin can toggle between Global Mode and Employer Mode anytime
  • In Employer Mode: employer uploads a PDF (e.g. company guide, job requirements) — AI uses it as context
  • Both modes can be active simultaneously (employer uses own key if set, falls back to global)

AI Features — Job Seeker

  • AI-powered job recommendations based on profile and behaviour
  • AI CV review: upload CV → get instant feedback and improvement suggestions
  • AI cover letter generator: tailored to specific job post
  • AI job match score: shows % match between candidate profile and job requirements
  • AI chatbot: answers candidate questions about jobs, application process, salary guides
  • Smart job search: natural language search ("accounting jobs in Dubai for 5 years experience")

AI Features — Employer / Recruiter

  • AI job description generator: employer inputs role title + key points → AI writes full JD
  • AI candidate screening: ranks applicants by match score automatically
  • AI interview question suggestions based on job role
  • Employer chatbot: guides employer through job posting, billing, dashboard questions
  • PDF context upload: employer uploads company guide → AI answers candidate questions using it

AI Features — Admin

  • AI content moderation: auto-flags suspicious or fraudulent job posts for review
  • AI spam detection: detects duplicate or fake employer accounts
  • AI analytics insights: plain-language summaries of platform performance ("This week IT jobs got 40% more applications than last week")

AI Chatbot Widget

  • Floating AI chat widget on all pages (web + mobile)
  • Admin can enable/disable per page or globally
  • Admin sets chatbot persona name and greeting message from admin panel
  • Chatbot trained on: job listings, FAQs, salary guides, platform policies
